Your library stays in this browser. Import directly from your signed-in Fanatical order history or restore a JSON backup.

Import from Fanatical

Open your Orders page and select Quick scan for new purchases. It checks the order list and retrieves details only for orders not already scanned locally. Use Full scan all purchases only when you need to rebuild the Fanatical library.

Import backup

Choose a Fanatical Library JSON backup exported below. Restoring replaces your local library after confirmation and resets scan history. Your Galactic link and settings are kept. The next quick scan rechecks all completed orders.

Galactic Library link

Optionally check a current Fanatical bundle against exact game, book/comic, and audiobook titles owned through your other connected libraries. This sends only the bundle titles being checked to your locally installed Galactic Library extension; it never transfers either full library.

    Privacy

    Purchase metadata is stored only in this browser. The importer reads Fanatical's session token only in the Fanatical page context; neither tokens nor raw order responses are stored, exported, or sent to another extension. Quick scans retain only SHA-256 fingerprints of completed-order IDs, never the IDs themselves.
