## Data and permission explanations

FAN reads the signed-in provider's order list/details, projects supported purchase records and saves them locally. The provider-context session token is used for Fanatical requests, not retained in backups or companion transfers. Disclose applicable website content/purchase and authentication handling accurately in the actual dashboard; lack of retention is not a blanket no-access claim. There is no developer-server collection. GL matching is optional and purchase synchronization requires account consent.

Storage saves library/preferences/accounts; unlimitedStorage permits large local libraries beyond the normal extension quota, subject to available disk space and browser-wide limits; scripting runs the signed-in Orders importer; alarms perform bounded synchronization retries; Fanatical host access supports acquisition and overlays. Firefox retains required data `none` for the existing local/first-party import and local-companion behavior; no third-party metadata service was added. Do not equate this declaration with no HTTP requests.
